# basic-network-security-guide

A junior-friendly guide to basic network security and best practices which explains how to protect computers, Wi-Fi networks
and information from common security threats.

## Objectives

1.Explains basic network security.
2.Describe common threats.
3.Recommend ways to protect a network.

##Project Files

1. docs/network-security-guide.md-which describes network security measures to be followed.
2. docs/security-checklist.md-which provides a security checklist.
3. SECURITY.md-explains safe use and reporting security concerns.

## Target Audience

Students, beginners and computer users who want to learn basic network security.

## Conclusion

Network security helps protect devices and information. Strong passwords, secure Wi-Fi, updates and firewalls help reduce risks.
