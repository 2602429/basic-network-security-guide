## Basic Network Security Guide

#Introduction
Network security means protecting computers, Wi-Fi and information from people who should from any unauthorized access.

## Common Threats

1.Weak passwords

2.Viruses and Malware

3.Unauthorized access

4.Unsafe Wi-Fi connections

## How to protect a Network
1.Use firewalls:
Enable the firewall and review it's rules to filter/ block unwanted network traffic. Keep router firmware updated.

2.Secure Wi-Fi:
Always change the default router administrator credentials when it is no longer needed, 
set a very strong, unique password and ensure use of WPA2-AES or WPA3 security. Use a separate guest network for visitors when possible. Review 
connected devices periodically.

3.Control Access:
Use individual accounts where possible and give each user only the permission required for their duties.
Remove access when it is no longer needed and enable multi-factor authentication for administrator accounts where supported.

4.Software Updates:
Update computers, applications, routers and other network devices to fix unknown security weakness.

5.Monitoring Activity:
Review available security logs and investigate suspicious connections or repeated failed logi attempts.

6.Data Backups: Back up important files regularly, protect backup copies and test that data can be restored.

## Simple Network Diagrams:

Internet-Router and firewall-Protected network-computers, phones and printers.

A firewall helps control network traffic, but other security measures are also necessary.

##Response to security incidents

1. Report the incident to the IT team or network administrator.

2. Record what happened and which devices were affected.

3. Follow the organization's incident-response instructions.

4. Do not delete relevant records or investigate beyond your authority.

##Conclusion

Strong, unique passwords, firewalls, secure Wi-Fi, software updates, data backups and monitoring activity help a network.

##Safe Use

Only access or test networks you own or have permission to access them.
