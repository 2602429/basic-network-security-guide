## Security Policy

#Purpose
This project provides basic educational information about network security

## Reporting a Security Concern
If you discover a possible security problem in an organization's network, report it to the authorized IT team or network administrator using
the organization's approved reporting method.

## Safe Use
1. Only access systems you have permission to use.
2. Never publish passwords, access tokens, private keys or confidential network information.
3. Do not take advantage of this guide to access other people's system without authorization.
4. Keep software updated to fix unknown security weakness and protect sensitive information.
